## Library folders

Reiverr automatically discovers local media from configured library folders. The user can configure the path of series and movies library folders separately, and there can be multiple library folders for each media type.

### Primary library folder

There is one primary library folder per media type, and it is where newly downloaded media is imported to. Other library folders will still discover new media.
